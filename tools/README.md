# Tools

Personal tools managed as a pnpm workspace.

## Setup

```bash
cd tools
pnpm install
pnpm build
```

## Packages

No tools have been added yet.

## Commands

Run a command across every tool:

```bash
pnpm build
pnpm lint
```

Run a command for one tool after adding it:

```bash
pnpm --filter <package-name> <command>
```
